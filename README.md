# Product Export Data Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing product export data using Microsoft Excel. The dataset contains information about fruit and vegetable exports across different countries during 2016.

The project uses Pivot Tables and Pivot Charts to analyze product-wise export quantities, order frequency, country-wise orders, and monthly export trends.

## 📂 Dataset Information

- **Total Orders:** 213
- **Total Export Quantity:** 1,029,734 Kg
- **Products:** Apple, Beans, Broccoli, Carrots, Mango, Orange
- **Categories:** Fruits and Vegetables
- **Countries:** 7
- **Year:** 2016

### Dataset Columns
- Order ID
- Date
- Category
- Product
- Unit (in Kg)
- Country

## 🎯 Project Tasks

### Task 1: Product-wise Export Quantity
- Calculate total export quantity for each product using a Pivot Table.
- Calculate the percentage contribution of Carrots to total export quantity.
- Visualize product-wise export quantities using a Pivot Chart.

### Task 2: Product Order Frequency
- Calculate how many times each product has been ordered.
- Create a Pivot Chart to visualize order frequency.
- Identify the total number of Apple orders.

### Task 3: Country-wise Order Analysis
- Analyze fruit and vegetable orders placed by each country.
- Compare country-wise order counts.
- Calculate the percentage of fruit orders from the United States, New Zealand, and Australia.

### Task 4.1: Monthly Product Export Analysis
- Analyze monthly export quantities for all six products.
- Compare monthly export trends.
- Identify changes in product-wise export quantities throughout the year.

### Task 4.2: Monthly Fruit Export Analysis
- Analyze monthly export quantities of Apple, Mango, and Orange.
- Compare monthly fruit export trends using Pivot Tables and Pivot Charts.

## 🛠️ Excel Skills Used

## 📊 Key Insights

- Mango recorded the highest export quantity at 397,374 Kg.
- Apple had the highest order frequency with 40 orders.
- Carrots accounted for approximately 13.30% of total export quantity.
- The United States recorded the highest number of orders with 57.
- May recorded the highest monthly export quantity at 203,339 Kg.
- Total exports across all six products reached 1,029,734 Kg.
